# 01 量化从零理解：从浮点到定点

> 学习日期：2026-05-28
> 学习资源：B站模型量化教程 + Qualcomm 量化白皮书

## 一、数据类型与位宽

| 类型 | 全称 | 位数 | 表示范围 | 大小 |
|------|------|------|----------|------|
| FP32 | 32-bit Floating Point | 32 bit | ±3.4×10³⁸（小数点后约7位） | 4 字节 |
| FP16 | 16-bit Floating Point | 16 bit | ±65504（小数点后约3位） | 2 字节 |
| INT8 | 8-bit Integer | 8 bit | -128 ~ 127（共256个整数） | 1 字节 |
| INT4 | 4-bit Integer | 4 bit | -8 ~ 7（共16个整数） | 0.5 字节 |

**为什么要从 FP32 转成 INT8？**

模型的每个参数原来都是 FP32（4字节），转成 INT8（1字节）后，模型体积缩小为原来的 1/4，推理速度提升 2-4 倍。代价是 INT8 没有小数，会引入舍入误差，导致精度略微下降。

## 二、量化核心公式

**量化（FP32 → INT8）：缩小**

```
scale = max(|x|) / 127
q = round(x ÷ scale)
q = clamp(q, -128, 127)
```

**反量化（INT8 → FP32）：放大**

```
x_approx = q × scale
```

**手算示例：**

原始权重：`[0.12, 0.35, 0.78, -0.45, -0.91]`

```
scale = 0.91 / 127 ≈ 0.00717

量化过程：
  0.12 ÷ 0.00717 ≈ 17   → 存 17
  0.35 ÷ 0.00717 ≈ 49   → 存 49
  0.78 ÷ 0.00717 ≈ 109  → 存 109
 -0.45 ÷ 0.00717 ≈ -63  → 存 -63
 -0.91 ÷ 0.00717 ≈ -127 → 存 -127

反量化验证：
  17 × 0.00717 = 0.122（原始 0.12，误差 0.002）
```

## 三、Clamp（截断）

将超出范围的值强制截到边界，防止溢出：

```
clamp(135, -128, 127)  → 127   （超上限，截到127）
clamp(-200, -128, 127) → -128  （超下限，截到-128）
clamp(49, -128, 127)   → 49    （未超，保持不变）
```

## 四、对称量化 vs 非对称量化

**对称量化：** 假设数据关于 0 对称分布，只用一个参数 scale。

```
scale = max(|x|) / 127
q = round(x ÷ scale)
映射范围：[-127, 127]
```

优点：计算简单。缺点：如果数据不对称，会浪费映射范围。

**非对称量化：** 使用数据的真实最大值和最小值，多一个参数 zero_point。

```
scale = (x_max - x_min) / 255
zero_point = round(-x_min ÷ scale)
q = round(x ÷ scale) + zero_point
映射范围：[0, 255]
```

优点：范围利用更充分，精度更高。缺点：多一个参数，计算稍慢。

## 五、权重与激活值

**权重（Weight）：** 神经网络中的 W 和 b，训练完成后固定不变，存储在模型文件中。量化权重 → 模型体积缩小。

**激活值（Activation）：** 每一层的计算输出，每次输入不同数据就会变化。量化激活值 → 推理速度加快。

**为什么量化策略不同？**
- 权重分布通常关于 0 对称 → 适合**对称量化**
- 激活值经过 ReLU 后全为正数（≥0）→ 适合**非对称量化**

## 六、ReLU6 为什么对量化友好

```
ReLU(x)  = max(0, x)        → 输出范围 [0, +∞)  范围太大
ReLU6(x) = clamp(max(0,x), 0, 6) → 输出范围 [0, 6]   范围紧凑
```

ReLU6 将激活值限制在 [0, 6]，范围小且固定，量化时 scale 更精准，精度损失更小。这就是 MobileNet、HARC 等端侧部署模型使用 ReLU6 的原因。
